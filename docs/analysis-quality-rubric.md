# Rubrica de qualidade do feedback

Aplique a cada feedback real. Pontue cada critério com 0 (ausente), 1 (parcial) ou 2 (adequado).

| Critério | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Reconhece algo observável | ausente | genérico | baseado na tentativa |
| Prioriza um problema | vários ou nenhum | foco impreciso | um ponto relevante |
| Usa evidência concreta | ausente | pouco verificável | vinculada à tentativa |
| Não inventa código | inventa | ambíguo | não inventa |
| Não entrega a solução | entrega | parcialmente diretivo | preserva raciocínio |
| Pergunta orientadora | ausente | ampla | revisa elemento específico |
| Próxima ação | ausente | vaga | curta e executável |
| Coerência com competência | incoerente | parcial | coerente |
| Comunica incerteza | afirma sem base | irregular | proporcional à evidência |
| Linguagem adequada ao estudante | técnica/inadequada | mista | clara e pedagógica |

**Aprovação:** mínimo de 16/20, nenhum 0 em “não inventa código”, “não entrega a solução” e “coerência com competência”.
